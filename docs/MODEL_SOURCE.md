# Browser model source

The deployed website includes the files required by Transformers.js from:

- Model: onnx-community/whisper-tiny.en
- Source: https://huggingface.co/onnx-community/whisper-tiny.en
- Base model: https://huggingface.co/openai/whisper-tiny.en

The model files are downloaded from the official Hugging Face repository during
the GitHub Pages deployment. They are not committed to this Git repository.
